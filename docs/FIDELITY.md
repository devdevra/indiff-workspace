# 원본 UI 교정 기준과 남은 기능 차이

## 관찰 근거

원본 웹 사이트 `https://choisukjune.github.io/indiff-app/`와 제공된 INDIFF 0.7.0 앱의 정적 텍스트를 분석한 작업입니다. 원본 앱 서버·클라이언트 실행 코드를 실행하거나 묶어 배포하지 않았습니다.

확인한 원본 디자인 단서:

- 기본 dark zinc: background hsl(240 10% 3.9%), foreground hsl(0 0% 98%), muted/border hsl(240 3.7% 15.9%)
- Pretendard 우선, 본문 14px, line-height 1.65
- 왼쪽 프로젝트 파일 트리 280px, 상단 바 32px, 하단 상태바 26px
- 사이드바/탭/하단바는 같은 zinc 계열 면. 본문은 더 어두운 문서 면
- 탭 폭 168px/max, 최소 96px. 활성 탭 아래 밝은 밑줄. 임시 보기의 제목은 이탤릭
- 재귀적 좌우/상하 분할 패널과 5px 잡기 영역, 실제 선은 1px
- 팀 화면은 좌측 팀·에이전트 목록, 중앙 대화방, 아래 입력상자 구조
- 보드는 점 배경, 자유 배치 236px 카드, 곡선 연결선, 양쪽 연결 점, 우하단 줌 도구
- 떠 있는 구슬과 펼치는 작업 상태 창

원본 CSS/HTML을 복사하지 않고 관찰된 치수·색상·동작 원칙을 새 코드로 구현했습니다.

## 이 단계의 기준

이 단계는 시각/상호작용 교정 초안입니다. 기존 대시보드형 재해석을 제거하고 원본의 파일→문서/도구 탭→분할 패널 작업 흐름을 되살리는 것이 범위입니다. 원본의 실제 AI·OS·파일 기능을 완성한 이식본으로 표시하지 않습니다.

## 상태별 목록

구현됨, Node 로직 검사 통과:

- dark zinc 구조/치수 선언, 빈 화면 원본 문구
- 문서 가상 경로/트리/읽기·편집/내보내기/가져오기/메모
- 임시/고정 탭·닫기·이동·재정렬 로직
- 재귀 좌우/상하 분할, 최대 4개 제한, 분할 비율 검증
- 보드 자유 좌표·곡선 계산·연결 DAG 검사·카메라 상태
- 로컬 규칙 실행, 저장소 원본 보호, 전체 백업/복원 스키마

구현했으나 실제 브라우저 조작·픽셀 검수 별도 필요:

- 실제 탭 드래그/분할 구분선/노드 포인터 드래그
- 390px 모바일 드로어/패널 전환/보드 터치 이동
- 팀 메모 입력·문서 textarea·복원 확인창의 최종 동작
- 원본 실제 화면과의 이미지 대조 및 오차 기록

부분 구현:

- 팀 구조와 역할·지시를 저장하지만 대화는 나의 로컬 메모만 저장
- 보드의 DAG는 로컬 텍스트 처리에 연결, AI 에이전트 실행·원본 세션 연결 없음
- 파일 트리는 브라우저 가상 경로. 실제 디스크/운영체제 프로젝트와 연결되지 않음
- 모바일도 같은 디자인 언어를 사용하지만 모든 패널을 한 번에 표시하지 않고 선택 전환
- 구슬은 새 CSS 도형으로 역할/상태만 보여 줌. 원본의 세션/실제 에이전트 상태 아님

미구현:

- 실제 Claude/Codex/AI 팀·에이전트/메시지 전송·도구 호출
- 터미널/CLI/세션 관리, MCP, 셸/OS 접근
- PDF/HWPX/오피스/미디어/도식 편집기, 원본의 웹 탭·브라우저 임베드
- 실제 파일시스템 등록/감시/저장/경로 이동·외부 편집 동기화
- 협업/계정/기기 간 동기화/모바일 원격 실행
- Windows EXE, Android APK, 설치·서명·업데이트

## 수정본의 명시적 제한

- 최대 4개 패널. 원본의 분할 한도와 같다고 주장하지 않음
- 원본 폰트 바이너리·상표 로고·캐릭터 자산은 포함하지 않음
- 네트워크 API 호출 없음. 규칙 실행을 AI 성공으로 표시하지 않음
- 원본의 메뉴 전체·키보드 조합 전체·문서 포맷 전체를 구현한 상태가 아님
- 기존 버전/소스는 복구 가능하게 보존. 동일 Sites에 owner-private 검수 버전으로 게시하며 원본 비교 검수를 계속함
