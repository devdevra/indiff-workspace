# 소스와 자산 권리 기록

작성일: 2026-10-17

## 이 작업본에 포함한 것

- 기존 독립 작성 Workspace Lab의 `lib/core.js`, `lib/storage.js`, Node 기반 정적 서버/빌드와 해당 테스트를 유지·확장했습니다. 이 소스는 작업본의 MIT 라이선스 범위입니다.
- UI HTML/CSS/JavaScript, 재귀 레이아웃/탭·보드 로직과 테스트는 이번 교정 단계에서 새로 작성했습니다.
- SVG는 범용 직선/사각형/돋보기/분할 아이콘을 직접 작성했습니다.
- 구슬은 CSS의 원/그라디언트/눈 점으로 새로 작성했습니다. 원본 캐릭터 파일이나 스프라이트를 복사하지 않았습니다.
- 샘플 문서는 이전 독립 구현의 예제입니다. 원본 앱 사용자 데이터가 아닙니다.

## 관찰만 한 것

- 원본 사이트 https://choisukjune.github.io/indiff-app/
- 제공된 INDIFF 0.7.0 앱의 정적 CSS/HTML/문자열에서 색상·치수·배치·조작 원칙을 확인했습니다.
- 원본 `server.js`를 `require`, import, eval, 셸 실행 또는 Node 실행하지 않았습니다.
- 원본 클라이언트 JavaScript도 실행하거나 이 작업본에 포함하지 않았습니다.
- 외부 Claude/Codex/AI 서비스 호출·로그인·업로드·유료 요청을 하지 않았습니다.

## 포함하지 않은 것

- 원본 서버·클라이언트 코드, 앱 패키지, 종속 라이브러리
- Pretendard 등 폰트 파일: 설치된 폰트 이름만 CSS fallback으로 참조
- 원본 이미지·아이콘 세트·로고·캐릭터·서명 키·토큰·사용자 파일
- 원본의 별도 라이선스가 필요한 문서/미디어 파서

## 배포 전 검토

INDIFF라는 이름은 원본과의 작업 맥락을 식별하기 위해 표시합니다. 원본 프로젝트의 MIT 또는 다른 라이선스/상표 허가가 확인되었다고 주장하지 않습니다. 실제 제품 배포 전에 원본 소스·브랜딩·별도 자산의 사용 권한과 공지 의무를 확인해야 합니다. 이 폴더의 MIT LICENSE는 독립 작성 소스에만 적용됩니다.
