# 검증 기준과 현재 상태

2026-10-17 UI 교정본. 기존 버전/소스를 보존하고 동일 Sites에 비공개 검수용 새 버전을 게시합니다.

## 통과

- `npm run check`: app/core/storage/layout/build/serve JavaScript 문법
- `npm test`: 74개 Node 단위/통합 검사
- 기존 코어의 결정적 실행·실패 전파·취소·용량 제한·저장 스키마·손상 원본 보호·UTF-8 가져오기 검사
- 새 레이아웃의 임시/고정 탭·닫기·재정렬/패널 이동·재귀 분할·4개 한도·분할 닫기·백업 round trip
- 새 UI 데이터의 잘못된 참조/중복 패널/경로/좌표/카메라/대화 크기 거부
- DAG 연결 생성·중복 연결 억제·자기/없는 참조/순환 연결 거부·곡선 좌표 계산

## 실사이트에서 확인한 범위

v3 비공개 검수 URL에서 홈, 파일 열기, 분할, 보드 진입이 정상 동작함을 확인했습니다. 이는 해당 4개 흐름의 확인이며 원본 픽셀 일치·전체 기능·모바일/Windows 앱을 검증한 결과는 아닙니다.

로컬 후속 후보의 모바일 문서 삭제 버튼 접근과 BOM 포함 JSON 백업 수용은 코드/Node 검사만 마쳤고 아직 사이트에 게시하지 않았습니다.

## 별도 실행 필요

`INDIFF_TEST_URL=http://127.0.0.1:4178 npm run test:browser`

`tests/browser_test.py`는 기존 Playwright/Chromium이 있고 소켓 생성이 허용된 환경에서 다음을 검사합니다. 이 작업 환경에서 Chromium 실행은 OS socket 권한 및 승인 경로 mount 오류로 시작되지 않아, 아래 항목을 통과했다고 기록하지 않습니다.

- 원본 규격 실제 치수/빈 화면
- 임시/고정 탭, 문서 편집·자동 저장·다시 열기·텍스트 안전성
- 메모, 분할 독립 문서, 탭 드래그 이동
- 보드 노드 포인터 이동·좌표 저장·곡선 연결·순환 거부
- 로컬 규칙 실행·완료 기록
- 팀 메모 저장 및 가짜 AI 응답 부재
- UTF-8 가져오기, 전체 백업/복원
- 390px 모바일 패널 전환·가로 넘침 부재
- 손상된 UI 저장 원본 보호

## 원본 비교 검수

별도 클라우드 브라우저에서 로컬 교정본 접근과 픽셀 비교를 별도 시도합니다. 원본 대비 결과가 확인되기 전에는 원본 충실도 완료·Windows/모바일 제품 완료로 판정하지 않습니다.

## 배포 조건

사용자 요청에 따라 기존 동일 Sites의 owner-private 접근을 유지하여 검수용 버전으로 게시합니다. 원본 시각/상호작용 비교와 명시적 기능 갭 검토를 계속합니다. EXE/APK·AI·파일 호스트는 이 단계에 포함되지 않습니다.
